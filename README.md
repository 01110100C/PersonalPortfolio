# Personal Portfolio

My personal portfolio website, built with React and Vite. It uses a retro computer theme: the site is framed like a classic beige computer monitor, with a CRT-style screen, pixel fonts, and pixel-art graphics.

## Pages

- **Home**: an introduction, my skills, my hobbies, and my education
- **Projects**: highlights from projects I've built, including Poll Pal, Send It, and Card Counter
- **Resume**: my resume
- **Contact**: ways to get in touch, plus links to my GitHub and LinkedIn

## Tech Stack

- React
- Vite
- React Router
- CSS

## Getting Started

You need [Node.js](https://nodejs.org/) installed.

```bash
cd PersonalPortfolio
npm install
npm run dev
```

Then open the local address that Vite prints (usually http://localhost:5173).

### Other Commands

| Command           | What it does                             |
| ----------------- | ---------------------------------------- |
| `npm run build`   | Builds the site for production in `dist/` |
| `npm run preview` | Serves the production build locally      |
| `npm run lint`    | Runs ESLint                              |

